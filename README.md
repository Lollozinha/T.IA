# T.IA

## 🧩​ Sobre o Projeto

T.IA: Aplicação mobile direcionada a apoiar o desenvolvimento cognitivo com inteligência artificial para crianças com Transtorno do Espectro Autista (TEA) – Nível I de suporte.

### 🎯​ Objetivo Principal

O principal objetivo deste projeto é o desenvolvimento de uma aplicação mobile para apoio ao desenvolvimento cognitivo de crianças com TEA, que combina jogos educacionais com suas instruções por meio de voice cloning baseada em IA dos responsáveis, mediadores ou outros agentes de atendimento e acompanhamento multilateral, como: psicólogos, pedagogos e fonoaudiólogos.
A aplicação também contemplará de funcionalidades destinadas ao gerenciamento das relações e interações entre seus consumidores e o sistema. Mediante a coleta de feedbacks contínuos e envio periódico de relatórios de performance e desempenho do menor aos seus respectivos responsáveis, a fim de acompanhar o seu progresso e engajamento nas atividades.

### 📲​ Funcionalidades

1. Cadastro de usuários.
2. Gravação e conversão de aúdio com IA (Inteligência Artificial).
3. Atividades educacionais.
4. _Feedbacks_ (Comentários) para responsáveis e educadores.

<br>

## Tecnologias e Linguagens

A aplicação mobile será desenvolvida com _front-end_ em _React Native_ (com o objetivo de abranger multiplataformas, como _Android_ e IOS), _back-end_ em Node JS e integração com a API _text-to-speech_ ChatterBox para clonagem de voz. Além disso, será desenvolvida através do Ambiente de Desenvolvimento Integrado (IDE, do inglês _Integrated Development Environment_) Visual Studio Code, com o banco de dados em MySQL gerenciado através do MySQL Workbench.
