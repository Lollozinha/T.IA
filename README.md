Descrição do Projeto:

Tupikê é um projeto educacional online voltado ao ensino da língua Tupi 

Objetivo:

O objetivo do projeto TupiKê visa desenvolver um website de ensino-aprendizado para o público multigeracional alfabetizado que busca aprender a língua Tupi. A aplicação permitirá que o usuário acesse aulas gravadas e ao-vivo, materiais de estudo e apoio, atividades de fixação referentes aos conteúdos dos módulos, ambiente de bate-papo interativo entre alunos e suporte técnico.
